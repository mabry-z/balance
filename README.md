# Balance

A free daily logic puzzle: place the weights so every row and column adds up to the same number. A sister game to [Sequence](https://mabry-z.github.io/sequence/).

## Run it

It's a static site with no build step. Turn on GitHub Pages for this repository (Settings → Pages → deploy from the `main` branch, root folder) and the game is live at `https://<username>.github.io/balance/`.

To test locally, run `python3 -m http.server` in this folder and open http://localhost:8000.

## Launch date

Puzzle 1 plays on the date set by `LAUNCH` near the top of the script in `index.html`. That's the only line to change. Puzzles are grouped by weekday, so Mondays stay easy and Sundays stay hard whatever date you pick. You don't need to regenerate anything.

## Puzzles

`puzzles.js` is written by `generate.js`. Don't edit it by hand.

```sh
node generate.js           # build 8 weeks (56 days) of puzzles, plus 2 practice weeks
node generate.js 12        # build 12 weeks
node generate.js --check   # re-verify every puzzle has exactly one solution and none repeat
```

`puzzles.js` holds two sets. `PUZZLES` is the real daily schedule. `PRACTICE` is played in preview mode before launch, and it never shares a puzzle with the schedule, so launch day is always a fresh puzzle. Change `SEED` or `PRACTICE_SEED` in `generate.js` to get different sets. Difficulty by day lives in `LEVELS`:

| Day | Grid | Empty squares | Repeated weights | Logic |
|---|---|---|---|---|
| Mon | 4×4 | 5 | none | one-gap lines only |
| Tue | 4×4 | 6 | none | one-gap lines only |
| Wed | 4×4 | 7 | up to 1 | any |
| Thu | 4×4 | 8 | 1–2 | needs more than one-gap lines |
| Fri | 5×5 | 10 | 1–3 | needs more than one-gap lines |
| Sat | 5×5 | 12 | 2–4 | needs more than one-gap lines |
| Sun | 5×5 | 14 | 3–6 | needs more than one-gap lines |

The generator builds a random grid of weights 1–9 where every line hits the target, then empties squares one at a time, keeping a square empty only if the puzzle still has exactly one solution. The solver in `solver.js` counts solutions by exhaustive search. When the list runs out, players see "No puzzle today", so keep a few weeks ahead.

The answers aren't stored anywhere. The game solves the puzzle in the browser only when a player taps Reveal.

## Scoring and sharing

Each placement is a move. A perfect solve uses one move per empty square. The share card colors every empty square by how many tries it took (🟩 first, 🟨 second, 🟧 third, 🟥 four or more), and it adds the move count and solve time. So two players' cards for the same puzzle almost never match. The timer starts when the player taps Play on the "Ready to play?" screen. It pauses, and hides the board, when they tap pause or leave the page.

## Preview, replays, and testing

- **Before launch**, the site plays the practice set with a day picker. The real puzzles stay out of sight.
- **After launch**, `#day3` replays an earlier day. Days that haven't arrived yet show "unlocks on…" instead.
- **`#test`** (or `#test-day30` for a specific day) opens the real schedule, including future days, so you can check upcoming puzzles. Keep that link to yourself.

None of these modes save stats. The puzzle data is in a public repo, so a determined player could still read future grids from `puzzles.js`. The answers aren't in it, though.

## Files

- `index.html` is the game, styles, and logic.
- `puzzles.js` holds the daily puzzles, generated by `generate.js`.
- `solver.js` is shared by the game and the generator.
- `manifest.webmanifest` and the `icon-*.png` files let players add Balance to their home screen.

Stats and streaks are stored in each player's browser. There are no accounts, cookies, or server.
